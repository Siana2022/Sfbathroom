## Decisiones tomadas

- **Resend** para correo interno; **Amazon SES** para marketing (selector por variable).
- **Zoho es una sola organización** para SF, FUX y DOT; no distingue empresa.
- **Zoho no se toca**: solo lectura (`GET`). El refresh token se revoca **después** del
  import final del día del cambio, no antes.
- La importación es **idempotente** (`origen + id_externo`) y respeta los vínculos
  manuales: si una fila se vinculó a mano, la reimportación no la pisa.
- El comercial **no ve el cuadro de mando**; las rutas permitidas se amplían una a una
  en `lib/supabase/middleware.ts`. `/ranking` e `/interacciones` están restringidas.
- El **registro de accesos** no se implementa hasta cerrar con el cliente retención,
  IP y quién consulta.
